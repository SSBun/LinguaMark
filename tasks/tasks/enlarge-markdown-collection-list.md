# 放大 Markdown 收藏列表页面

Status: Completed (2026-09-01 16:42)
Kind: Task

## Scope

- 包含：收藏与最近浏览弹窗的默认尺寸、当前页面内调整尺寸及内部列表布局。
- 不包含：尺寸偏好持久化或收藏数据与操作变更。

## Target
- [x] T1: Markdown Viewer 的收藏与最近浏览列表在桌面端以更大的默认尺寸打开。
- [x] T2: 用户可在桌面端拖动弹窗边缘调整宽度和高度，尺寸始终限制在可视区域内。
- [x] T3: 窄屏布局与关闭操作保持可用，用户调整的尺寸不跨页面持久化。
- [x] T4: 收藏与最近浏览保留为两个独立列表；每个列表内的条目从顶部向下紧凑排列，使用一致的 cell 内边距与间距且不拉伸填满列表高度。

## Plan

1. 保留收藏与最近浏览两个列表及现有桌面／窄屏分栏。
2. 让列表隐式行按内容高度排列并顶端对齐，复用统一 cell 内边距与间距。
3. 验证稀疏列表不拉伸、多条目滚动、尺寸调整、类型与构建结果。

## Result

- T1: Chrome 冒烟在 1440×1000 视口测得收藏弹窗默认 1080×780px，明显大于原 720px 宽度。
- T2: 最新 Chrome 紧凑列表冒烟再次使用原生 resize 手柄放大弹窗，稀疏 cell 保持内容高度且视口边界未回归。
- T3: 最新 Chrome 冒烟切换至 600px 窄屏后仍使用既有单列规则并可关闭，尺寸未增加持久化逻辑。
- T4: Chrome 在保留全部收藏和最近浏览两个列表的前提下测得稀疏 cell 高度低于 60px、垂直间距恒为 8px、四向内边距均为 10px；32 条长列表可滚动，调整弹窗后 cell 不拉伸。
