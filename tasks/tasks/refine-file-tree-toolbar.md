# 调整文件树工具栏并增加定位当前文件

Status: Completed (2026-09-01 15:07)
Kind: Task

## Scope

- 包含：目录文件树工具栏的位置、文件夹全量展开／折叠切换，以及当前已打开目录文件的列表定位。
- 不包含：文档标题目录、文件打开流程或侧栏整体显隐行为。

## Target
- [x] T1: 文件树的控制区显示在目录视图上方。
- [x] T2: 全部展开与全部折叠合并为一个可在两种操作间切换的按钮。
- [x] T3: 点击定位按钮后，当前打开的文件在文件列表中被选中。
- [x] T4: 当前打开的目录文件在文件树恢复后仍可被定位，定位按钮不会因初始化顺序而错误禁用。

## Plan

1. 将目录文件树控制区与可滚动列表面板分离。
2. 用单一按钮切换全部展开／折叠，并让文件树恢复时同步当前文件选择。
3. 验证默认折叠、往返切换、初始化后的当前文件定位、类型检查与构建。

- T1: 最新版构建在 Chrome 冒烟检查中确认工具栏 DOM 与可视边界均位于文件树面板上方，桌面与 800px 窄屏均成立。
