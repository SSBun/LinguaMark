# 设计 LinguaMark 扩展图标

Status: Completed (2026-08-29 12:06)
Kind: Task

## Scope

- 包含：依据用户提供的视觉参考生成一张含六个 LinguaMark 图标变体的探索图；用户选定后生成独立绿色幕布源图，取得批准并产出透明 1024×1024 主图。
- 不包含：Chrome 尺寸变体、manifest 接入，以及未经用户另行选择的平台素材。

## Target
- [x] T1: 用户明确批准一张代表 LinguaMark 的独立绿色幕布图标源图。
- [x] T2: 交付经验证的 1024×1024 透明 RGBA PNG 主图，透明角有效且批准的主体保持可见。
- [x] T3: 展示一张匹配用户参考风格、包含六个可区分 LinguaMark 图标变体的探索图；每个变体都清楚呈现一段文本，并以三种颜色标记其中内容，供用户选择。

## Plan

1. 分析用户提供的视觉参考并生成六变体探索图。
2. 用户选定变体后，生成并展示独立绿色幕布源图，等待明确批准。
3. 移除绿色背景，验证并展示透明主图。

## Decisions

- 以用户提供的图片作为视觉风格权威参考：近黑底、粗大圆角几何、极少细节、无文字与阴影。
- 每个方案必须一眼呈现为由多条横向线段组成的文本段落，并在文本内部使用三种明确不同的标记颜色；不得再以书本、页面堆叠、圆点或抽象框架作为主体。
- 六个方案保持同一主体语义与风格，只变化文本排版和色块构图；先生成一张探索图，再将选中方案生成独立源图。
- 用户选择第二个变体作为扩展图标。

## Result

- T3: 已生成并展示 1536×1024 PNG 探索图；六个变体均由五行段落线构成，并在段落内部完整使用蓝、红、紫三种标记颜色。
- T1: 用户以“cnofirm”明确确认已展示的第二方案独立绿色幕布源图；批准对象为 linguamark-icon-source-v3.png。
- T2: create-app-icon helper 以 #00ff00 为键生成 master PNG；独立检查确认 1024×1024、RGBA、四角 alpha 均为 0，489437 个可见像素保留已批准主体。
- Review gate: Skipped — 用户未要求独立或对抗式审查。

## Verification

- Passed: 透明主图验证为 PNG、1024×1024、4 通道 RGBA；四角透明且主体非空，批准的第二方案构图保持可见。
